README

Importar el proyecto

1. Descargar y descomprimir el proyecto.
2. Abrir la carpeta del proyecto en Eclipse 2026
3. Importar el proyecto
4. Verificar que los archivos `.java` estén ubicados correctamente.

Ejecutar el proyecto

1. Abrir `Main.java`.
2. Ejecutar el método `main`.
3. Los resultados de las pruebas se muestran directamente en la consola.

Probar el proyecto

Las pruebas estan en la clase `Main.java`.
Se crean objetos de las diferentes clases y se ejecutan los métodos principales del sistema.

* Creación de estudiantes, operadores y responsables.
* Creación de campañas y actividades.
* Registro de participaciones.
* Manejo de EcoPuntos y movimientos.
* Creación de materiales y puntos ecológicos.
* Creación de recolecciones.
* Creación de rutas y paradas.
* Creación, asignación y cierre de reportes.

Para las pruebas la capacidad de los arreglos fue definida al momento de crear los objetos.
En los datos de prueba utilizados en `Main.java`, los arreglos no se llenan completamente, el sistema controla la cantidad de elementos almacenados por medio de variables como `cantidadActividades`, `cantidadParticipaciones`, `cantidadMateriales`, `cantidadMovimientos` y `cantidadParadas`.
